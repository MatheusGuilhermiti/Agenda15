Descrição

Este projeto é um portfólio pessoal desenvolvido para apresentar meu perfil, minha formação, habilidades e alguns projetos realizados durante meus estudos em Desenvolvimento de Sistemas.

Tecnologias utilizadas
- HTML5
- CSS3
- Bootstrap 5.3.3
- Devicon para os ícones das tecnologias
- GitHub Pages para publicação

Como o projeto funciona
O site é dividido em seções: Perfil, Habilidades, Projetos e Contato. O menu superior utiliza links internos para levar o visitante diretamente a cada seção. O Bootstrap é utilizado para montar o menu responsivo, organizar as colunas e criar os cards. O CSS complementa a aparência e os efeitos visuais.

As imagens utilizadas no site ficam na pasta imagens, que deve ser mantida junto do arquivo index.html no repositório.
Recurso novo adicionado

Foi adicionado um efeito de animação nos cards da seção de projetos. Ao passar o mouse sobre um card, ele sobe levemente, recebe uma sombra e a imagem apresenta um pequeno zoom. Também foram adicionados efeitos de movimento nos cards de habilidades.

Como o recurso foi implementado
O recurso foi implementado com CSS, usando transition para deixar a mudança suave e :hover para ativar os efeitos quando o ponteiro do mouse passa sobre os cards. A propriedade transform movimenta e aumenta levemente os elementos, enquanto box-shadow cria a sombra. Não é necessário instalar bibliotecas adicionais para esses efeitos.
